Detail teknis di balik layar
  • Masuk dengan Google mengarahkan user ke Google lalu kembali ke /auth/callback. User baru langsung masuk ke langkah 4 (kartu), sedangkan user lama langsung ke lobi.
  • Nomor anggota diambil dari urutan di database (profiles.member_no) dan bersifat publik. Email tidak pernah ditampilkan.
  • "Pengunjung hari ini" hanya berupa angka, tanpa nama user lain, demi privasi.
  • Aksesibilitas: font tulisan tangan hanya untuk isian dan dekorasi. Label form memakai font yang jelas, dan kontras teks memenuhi standar WCAG AA.
  • Gagal login ditampilkan oleh petugas lewat balon kata ("Hmm, kata sandinya belum cocok…"), plus pesan error biasa di bawah isian.
